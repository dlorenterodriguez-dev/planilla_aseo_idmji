# IDMJI Voluntariado Biblias

Aplicación Flutter para gestionar las voluntarias y planillas de Biblias de la IDMJI.

## Funcionalidades actuales

- Gestión de voluntarios
- Persistencia local mediante SharedPreferences
- Planificación semanal
- Cultos:
  - Martes - Alabanza
  - Sábado - Estudio
  - Domingo - Enseñanza
- Detección de conflictos horarios
- Limpieza de semana

## Tecnologías

- Flutter
- Dart
- SharedPreferences
