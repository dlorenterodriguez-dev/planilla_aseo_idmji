# IDMJI Voluntariado Aseo

Aplicación Flutter para gestionar las voluntarias y planillas de Aseo de la IDMJI.

## Funcionalidades actuales

- Gestión de voluntarios
- Persistencia local mediante SharedPreferences
- Planificación semanal
- Planificación mensual
- Dos voluntarias diferentes por culto
- Autoasignación equitativa según carga e histórico
- Gestión de disponibilidad y periodos de ausencia
- Histórico corregible y copias de seguridad
- Cultos:
  - Martes - Alabanza
  - Sábado - Estudio
  - Domingo - Enseñanza

## Tecnologías

- Flutter
- Dart
- SharedPreferences
